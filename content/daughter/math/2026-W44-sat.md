# Math — Saturday

## 1. Warm-up (3 minutes, no pencil)

**Happy Counting.** Grown-up points up or down. Start at 6, count up to 14, back down to 9, up to 17.

**Partners to 5.** Grown-up says a number, you say the partner that makes 5. Fast!
3 → ___   1 → ___   4 → ___   0 → ___   2 → ___   5 → ___

**Partners to 10 (fingers up).** Show the number on your fingers, then tell how many are down.
7 → ___   9 → ___   5 → ___   8 → ___

## 2. Look (1 minute)

Here are some spiders in a 5-group.

●●●●●  ●●●

How many spiders? Don't count them one by one. Say "5 and 3 is ___."

## 3. Work (4 minutes)

**1.** Fill in the number bond. 8 is the whole.

```
        ( 8 )
       /     \
    ( 5 )   (   )
```

**2.** Doubles. Draw dots to match, then write the total.

4 + 4 = ___        3 + 3 = ___        5 + 5 = ___

**3.** Read, Draw, Write. *(Grown-up reads aloud twice.)*

> {{kid.name}} saw 6 spiders on the web. 3 more spiders crawled on. How many spiders are on the web now?

Draw it: ☐☐☐☐☐☐☐☐☐☐
Write the number sentence: ___ + ___ = ___
Answer in a sentence: There are ___ spiders on the web.

**4.** True or false? Circle one. Prove it with a drawing.

4 + 2 = 2 + 4      True  /  False
3 + 3 = 7          True  /  False

## 4. Exit Ticket (2 minutes)

**5.** Fill in the number bond. 10 is the whole, 6 is one part.

```
        ( 10 )
       /      \
    ( 6 )    (   )
```

**6.** Circle the 5-group, then write the total.

●●●●●●●●  →  ___

**Tell your grown-up:** How did you figure out the last one?
